# Mops cheat sheet

The canonical examples are bundled with the [mops skill](../skills/mops/SKILL.md). Read the
[topic index](../skills/mops/references/README.md), or run `mops examples`. Run `mops examples editing` to choose an
editing approach and `mops examples all` to read every topic.

Research evidence is recorded in the [transcript source index](mops-transcript-sources.md).
